# Jotta

Login:

```bash
jotta-cli login
```

(laptop) exclude folders (`Games`, `Entertainment`, `Edits` and `Dots/Games`):

```bash
jotta-cli sync selective add
```

(desktop) Sync:

```bash
jotta-cli sync --root /run/media/will/2TB/Dropbox
```

(laptop) Sync:

```bash
jotta-cli sync --root /home/will/Dropbox
```
